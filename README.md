# Motion Graphics

A practical skill library for motion design, animation prompts, title design, transitions, camera movement, compositing, and open-source video-generation workflows.

## Areas

- Motion design principles
- Animation styles
- Prompt patterns
- Camera and object motion
- Typography animation
- Logo and title animation
- Compositing
- Open-source AI video
- Higgsfield-style cinematic motion workflows

## Open-source direction

The repository focuses on workflows that can be recreated or adapted with open tools. Wan and ComfyUI are useful references for self-hosted video generation. Commercial tools can be studied for motion ideas, but their proprietary presets are not copied.
