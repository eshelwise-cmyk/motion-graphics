# Motion Style Library

## Minimal editorial

Traits: restrained movement, clean typography, deliberate spacing, short transitions.

Prompt pattern:

> Minimal editorial motion graphic, clean geometric layout, restrained camera movement, precise typography animation, controlled easing, subtle depth, polished studio finish.

## Kinetic typography

Traits: words drive the movement, rhythm follows the message, strong scale and timing changes.

Prompt pattern:

> Kinetic typography sequence, bold type hierarchy, words entering and exiting on rhythm, varied scale, directional motion, clean background, precise easing.

## Liquid / organic

Traits: flowing shapes, soft deformation, continuous motion, organic easing.

Prompt pattern:

> Abstract organic motion, fluid shapes deforming continuously, soft lighting, layered depth, smooth slow movement, seamless transitions.

## Futuristic interface

Traits: grids, data-like elements, restrained glow, modular transitions.

Prompt pattern:

> Futuristic interface motion graphic, modular grid, precise UI elements, subtle depth, controlled glow, fast clean transitions, technical visual language.

## Cinematic title

Traits: slow camera movement, depth, atmosphere, controlled reveal.

Prompt pattern:

> Cinematic title sequence, atmospheric environment, layered depth, slow deliberate camera push, restrained particles, dramatic but controlled lighting, elegant title reveal.

Prompts describe a target style. They do not reproduce proprietary presets from any specific service.
