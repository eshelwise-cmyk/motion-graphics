# Open-Source Higgsfield-Style Workflow

Higgsfield is a proprietary creative video platform. This repository does not reproduce its private presets or assets.

For a self-hosted alternative, build the workflow from open video models and a node-based interface.

## Recommended path

1. Use ComfyUI as the workflow layer.
2. Use an open video model such as Wan for image-to-video or text-to-video where supported.
3. Start with a strong still image.
4. Describe one camera move and one subject action.
5. Generate short variations.
6. Select the best motion.
7. Finish in the editor or compositor.
